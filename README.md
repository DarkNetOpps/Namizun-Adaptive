# Namizun Adaptive

## معرفی

Namizun Adaptive یک سیستم مدیریت مصرف ترافیک شبکه است که برای سرورهایی طراحی شده که محدودیت نسبت مصرف دانلود به آپلود دارند.

این پروژه با ایجاد ترافیک آپلود کنترل‌شده و تطبیقی، کمک می‌کند نسبت مصرف شبکه مدیریت شود.

---

## مشکل

بعضی دیتاسنترها برای سرورهای دارای ترافیک نامحدود، قوانین مصرف نسبت آپلود به دانلود دارند.

مثال:

اگر قانون دیتاسنتر:1GB Download = 10GB Upload

باشد، مصرف بالای دانلود بدون ایجاد آپلود کافی ممکن است باعث محدودیت سرویس شود.

---

## راهکار Namizun

Namizun با بررسی وضعیت شبکه و اجرای uploader تطبیقی:

- میزان مصرف دانلود را بررسی می‌کند
- نسبت آپلود مورد نیاز را تنظیم می‌کند
- تعداد uploader ها و حجم ارسال را به صورت پویا تغییر می‌دهد
